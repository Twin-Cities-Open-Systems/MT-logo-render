# Agent Prompt 03 — CLI Contract

## Objective
Define the command-line interface contracts for the render engine:
- Command structure: resolve, render, doctor, list
- Input/output specifications for each command
- Exit codes and error handling
- Flag and option specifications

## Output
- Update docs/CLI_CONTRACT.md with implementation-ready specifications
- Define JSON schemas for command inputs/outputs
- Document argument parsing and validation rules

## Constraints
- No code.
- Focus on CLI ergonomics and machine-readable outputs.
- Design for both human and programmatic usage.
