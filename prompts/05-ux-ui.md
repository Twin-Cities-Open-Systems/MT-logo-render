# Agent Prompt 05 — CLI UX

## Objective

Design the command-line user experience for the render engine:

- Command discoverability and help systems
- Error messages and validation feedback
- Progress indicators for long operations
- Output formatting for human vs machine consumption

## Output

- Update docs/UX_UI.md with CLI design principles
- Document error handling patterns
- Specify progress reporting and logging levels

## Constraints

- No code.
- Focus on CLI ergonomics: tab completion, sensible defaults, clear error messages.
- Design for both interactive and scripted usage.
